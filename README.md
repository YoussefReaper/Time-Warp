# Welcome
this is Time Warp, a chrome extension made especially for those who want to see the past versions of any website they visit.
Or if you're a designer who wants to notice the improvements by comparing two versions in front of you side by side.

## installation
#### 1- download the zip file.
#### 2- go to chrome extension manager
#### 3- turn on developer mode
#### 4- press load unpacked and choose the zip file ***AFTER Unzipping!***

### ENJOY!!
compare as you like!
